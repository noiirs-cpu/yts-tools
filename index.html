YTS Tools for MR YSDIY

ใส่รหัสเข้าใช้งานของคุณ (ได้รับจากทีม MR YSDIY) ใส่ครั้งเดียว เบราว์เซอร์นี้จะจำไว้

YTS Tools for MR YSDIY by Noii & Pierrick

สร้างเสียง 11Labs หาคีย์เวิร์ด หาคลิป ตัดเสียงเงียบ และดึงคอมเมนต์ YouTube ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

ตัดเสียงเงียบ

ตัดช่วงเงียบหัวและท้ายไฟล์ และย่อช่วงหยุดระหว่างคำให้สั้นลง ได้ไฟล์ MP3 320kbps ไฟล์ไม่ถูกอัปโหลดไปไหน

ลากไฟล์ MP3 มาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์ (เลือกได้หลายไฟล์)
    ตั้งค่าเพิ่มเติม

    ถ้าตัดไม่เจอช่วงเงียบ ลองลดเป็น -35

    ดึงคอมเมนต์ YouTube

    ดึงคอมเมนต์และคำตอบทั้งหมดเป็นไฟล์ JSON พร้อมโยนให้ Claude หรือ ChatGPT ต้องใช้ YouTube Data API v3 key ของตัวเอง ขอฟรีได้ที่ Google Cloud Console

    หาคีย์เวิร์ด YouTube Shorts

    ให้ AI หาคีย์เวิร์ดที่คนดูพิมพ์ค้นหาจริงสำหรับนีชของคุณ แบ่ง 6 หมวด พร้อมระดับการค้นหา ความยากในการแข่ง และไอเดียคลิปที่มีโอกาสไวรัล

    หาคลิปจาก X และ IG

    สร้างคำสั่งให้ AI หาคลิปจริงที่มีจังหวะพีค engagement ดี และทำ commentary ได้ โหลดผ่าน cobalt.tools เป็น MP4 ตั้งชื่อไฟล์ให้ เซฟลง Desktop\Clips\นีช พร้อมรายการคลิปและชื่อคลิปแบบ SoUnseen ต้องใช้กับ AI ที่ควบคุมคอมพิวเตอร์ได้ เช่น Claude Code หรือ Claude Desktop เพราะต้องโหลดไฟล์ลงเครื่อง

    ใช้ภาษาอังกฤษสั้นๆ เพราะจะเอาไปตั้งชื่อไฟล์และโฟลเดอร์ด้วย

    เช็คกฎ YouTube Shorts Commentary

    ตรวจว่าคลิป Shorts แนว commentary เสี่ยงผิดกฎ YouTube ไหม ทั้ง Community Guidelines ลิขสิทธิ์และ fair use นโยบายสร้างรายได้ ความเหมาะกับโฆษณา และกฎเฉพาะของ Shorts (ความยาว Content ID ลายน้ำ คลิปไม่เป็นต้นฉบับ) ผลที่ได้เป็นการประเมินความเสี่ยงจาก AI ไม่ใช่คำปรึกษาทางกฎหมาย

    ลากคลิปที่ตัดเสร็จมาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์ (MP4, MOV, WebM) ไม่บังคับ แต่จะเช็คได้แม่นขึ้น
